<h2>📖 How to Use ffv – A Simple Guide</h2>

<h3>Using the Interactive Screen (TUI)</h3>
When ffv opens, you'll see a list of choices. Here's what each one generally does:

1. <strong>Convert Video:</strong> Press Enter, then type or browse to select your video file. Next, type the format you want (like <code>mp4</code>, <code>avi</code>, <code>mov</code>). Press Enter, and watch it work!
2. <strong>Trim Video:</strong> Choose this, then select your video. Enter the start time (like <code>00:00</code>) and end time (like <code>00:30</code>), and it keeps only that part.
3. <strong>Merge Videos:</strong> Select two or more video files (press spacebar to select each), then press Enter. They'll become one big video.
4. <strong>Extract Audio:</strong> Pick a video, and ffv will pull out the sound and save it as an MP3 file.

<h3>Using Commands (CLI)</h3>
If you feel brave, you can type commands directly. It's actually easier than it sounds. For example:

- To convert a video: <code>ffv convert movie.avi movie.mp4</code>
- To trim: <code>ffv trim movie.mp4 --start 00:10 --end 00:45</code>
- To see all commands: type <code>ffv --help</code> and press Enter.

Don't worry about memorizing – the interactive screen shows you everything you need.
